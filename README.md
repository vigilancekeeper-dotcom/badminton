# Badminton Group Manager

Badminton Group Manager — the current working browser application.

## Current version

This version preserves the existing workbook-based application. It loads the Badminton master workbook in the browser and supports the existing dashboard, members, transactions, monthly fee status, archive, settings, import and export workflows.

The application does **not** contain passwords, API keys, or private database credentials.

## GitHub Pages

The application entry point is `index.html`.

The next development phase will move the shared data layer to a hosted database so all group members can see the same live data, while write operations remain restricted to administrators.
